# 레이아웃 카탈로그

`scripts/describe_template.py`가 템플릿에서 직접 뽑은 표입니다. 템플릿을 다시 만들면 이 파일도 다시 생성합니다.
spec에서는 **역할 이름**(표의 첫 열)을 키로 씁니다. 비워 둔 역할은 슬라이드에서 자동으로 지워집니다.

## 분량 한도 (넘으면 슬라이드를 나눕니다)

| 역할 | 한도 |
|---|---|
| `title` | 명사 위주 최대 4단어, 명사형 종결 (주장은 band에) |
| `section` | 섹션 이름 그대로 (Background, Method …) |
| `band` (하단) | 3~4줄, 한 줄 약 40자 (32pt, 줄간격 1.5). 2단은 `> ` |
| `band` (D 상단) | 2~3줄 |
| `explain` | 최대 8줄 (`> ` 보조 줄 포함, 줄간격 1.5), 줄당 약 16자. 더 필요하면 `line_spacing` 1.2 |
| `body_left/right` | 3~4개 항목, 각 항목 아래 보조 줄 1개 |
| `statement` | 한 문장, 약 30자 |
| `toc` items | 4~7개 |
| `source` | 한 줄: `Author et al., Venue Year` 또는 `arXiv:XXXX.XXXXX` |

## 그림 비율에 맞는 레이아웃 고르기

그림 영역은 레이아웃마다 비율이 다릅니다. 비율이 맞지 않으면 그림이 작아집니다. `build_deck.py`는 그림이 영역의 45% 미만을 채우면 경고합니다.

| 그림 가로:세로 | 추천 | 그림 영역 (in) |
|---|---|---|
| 3:1 이상 (가로로 긴 곡선, 파이프라인) | A | 18.0 × 5.1 (3.5:1) |
| 약 2:1 | C (해설 포함) 또는 G + `image` | 10.4 × 5.1 (2:1) / 18.5 × 8.2 (2.3:1) |
| 약 1.5:1 이하 (정사각형에 가까운 패널) | B (두 개 비교) 또는 C | 8.9 × 5.1 (1.75:1) |
| 여러 패널이 섞인 큰 figure | 패널별로 잘라 A/B/C에 나눔 | – |

그림 전체를 한 장에 꼭 보여야 하면 `G_TitleOnly`에 `{"type": "image", "box": [0.75, 2.25, 18.5, 8.2]}`로 넣고, 설명은 노트에 둡니다.

## 자유 영역 (shapes의 `"frame": "zone"` 기준)

`frame: "zone"`이면 `box`를 영역 대비 비율 `[x, y, w, h]`(0~1)로 씁니다. 생략하면 슬라이드 절대 좌표(인치)입니다.

| 레이아웃 | 영역 x, y, w, h (in) |
|---|---|
| A, B, C, F | 0.75, 2.25, 18.50, 5.10 (밴드 위) |
| D | 0.75, 4.45, 18.50, 6.00 (상단 밴드 아래) |
| E | 0.75, 2.30, 18.50, 7.95 |
| G, H | 0.75, 2.25, 18.50, 8.20 |

하단 바는 y = 10.74 in부터 시작합니다. 도형은 그 위에서 끝나야 합니다.
